# ESP32 LED Blink

A simple Arduino project that blinks an LED using an ESP32.

## Hardware
- ESP32 DevKit
- LED
- 220Ω resistor (optional for external LED)

## Pin
- GPIO 2

## Code

The LED turns on for one second and off for one second repeatedly.

## How to Upload
1. Open the project in Arduino IDE.
2. Select your ESP32 board.
3. Select the correct COM port.
4. Click Upload.
